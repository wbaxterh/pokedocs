Branding compiler (S1.4.1/S1.4.2): `compileBranding` turns a `branding` block into the complete computed theme — seven-shade Infima ladders for both color modes using the official Docusaurus generator's lightness steps, a dark-mode primary lifted with the smallest white tint (≥15%) that clears WCAG AA against Infima's dark background, logo light/dark normalization, favicon and font handling, and a debug flag that prints every computed value.
