The scaffolder is real (S1.1.1–S1.1.3): `npx create-pokedocs my-docs` generates a docs-only site — docs at the root path via `@pokedocs/preset`, autogenerated sidebar, a landing page driven entirely by config, agent authoring scaffold (AGENTS.md/CLAUDE.md with the site's conventions interpolated), a brand-colored generated logo, and zero template cruft. Interactive prompts cover site name, brand color, logo, and deploy target, with `--brand-color`/`--deploy`/`--yes` flags for non-interactive use; `--deploy github-pages` emits a working Pages workflow. `@pokedocs/plugin-mermaid-ssr` now declares its `playwright` dependency explicitly — standalone consumers previously hit ERR_MODULE_NOT_FOUND because `mermaid-isomorphic` leaves it as an optional peer.
