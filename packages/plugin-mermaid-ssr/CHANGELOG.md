# @pokedocs/plugin-mermaid-ssr

## 0.1.0

### Minor Changes

- [#65](https://github.com/wbaxterh/pokedocs/pull/65) [`683f6be`](https://github.com/wbaxterh/pokedocs/commit/683f6be242ab3a1cdc5791d7c2175cde6f4cd0b7) Thanks [@wbaxterh](https://github.com/wbaxterh)! - Build-time mermaid (S1.3.1–S1.3.3, shipped in [#61](https://github.com/wbaxterh/pokedocs/issues/61)): `rehypeMermaidSsr` compiles every mermaid fence to inline SVG during the build with the diagram source preserved in `data-mermaid-source` for agents, and fails the build with file/line/caret diagnostics on invalid syntax. One shared transformer across all files; the ESM-only engine loads via a dynamic import deferred to transform time.

### Patch Changes

- [#56](https://github.com/wbaxterh/pokedocs/pull/56) [`2ed5718`](https://github.com/wbaxterh/pokedocs/commit/2ed57185f7f70061ea4b1cd7ebacdaa087ab1116) Thanks [@wbaxterh](https://github.com/wbaxterh)! - Initial package skeletons: typed public contracts for the full PRD package map (M0).

- [#67](https://github.com/wbaxterh/pokedocs/pull/67) [`8151c79`](https://github.com/wbaxterh/pokedocs/commit/8151c79a948eb122c542b0ccf4af4d439ca2e8f3) Thanks [@wbaxterh](https://github.com/wbaxterh)! - The scaffolder is real (S1.1.1–S1.1.3): `npx create-pokedocs my-docs` generates a docs-only site — docs at the root path via `@pokedocs/preset`, autogenerated sidebar, a landing page driven entirely by config, agent authoring scaffold (AGENTS.md/CLAUDE.md with the site's conventions interpolated), a brand-colored generated logo, and zero template cruft. Interactive prompts cover site name, brand color, logo, and deploy target, with `--brand-color`/`--deploy`/`--yes` flags for non-interactive use; `--deploy github-pages` emits a working Pages workflow. `@pokedocs/plugin-mermaid-ssr` now declares its `playwright` dependency explicitly — standalone consumers previously hit ERR_MODULE_NOT_FOUND because `mermaid-isomorphic` leaves it as an optional peer.
